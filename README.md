# Рекурсивная канбан-доска

Однофайловая HTML-страница для ведения задач в формате рекурсивного канбана.

Обычная канбан-доска состоит из трёх колонок: **Запланировано**, **В процессе**, **Сделано**. В этом проекте каждая задача может открываться как отдельная вложенная доска с такими же колонками. Так можно бесконечно декомпозировать большие задачи на подзадачи, подподзадачи и так далее.

Проект работает полностью в браузере, без сервера и базы данных. Данные сохраняются в `localStorage`, а также могут экспортироваться и импортироваться через JSON-файл.

---

## Возможности

- Три стандартные колонки:
  - `Запланировано`
  - `В процессе`
  - `Сделано`
- Рекурсивная вложенность задач.
- Открытие вложенной доски по клику на карточку.
- Drag-and-drop для смены статуса задачи.
- Drag-and-drop для изменения порядка задач внутри колонки.
- Перетаскивание задачи внутрь другой задачи через специальный квадрат в углу карточки.
- Перенос задачи выше по пути через хлебные крошки.
- Задачи-ссылки: одна и та же задача может отображаться в нескольких местах.
- Поиск по названию и описанию задач.
- Создание ссылки на найденную задачу прямо из результатов поиска.
- Навигация назад/вперёд кнопками браузера.
- Экспорт всей доски в JSON.
- Импорт доски из JSON или `.txt` файла.
- Автосохранение в браузере.
- Адаптивный интерфейс для ПК и небольших экранов.

## Как пользоваться

### Создание задачи

В верхней панели введи:

- название задачи;
- описание или заметку, если нужно;
- нажми **Добавить задачу**.

Задача появится в текущей открытой доске в колонке **Запланировано**.

### Открытие вложенной доски

Кликни по карточке задачи. Откроется внутренняя доска этой задачи.

Например:

```text
Главная / Поиск работы / Составить резюме
```

### Возврат назад

Можно вернуться:

- через хлебные крошки;
- через кнопку браузера **Назад**;
- через кнопку браузера **Вперёд**.

## Drag-and-drop

### Смена статуса

Перетащи задачу в нужную колонку:

- **Запланировано**
- **В процессе**
- **Сделано**

### Изменение порядка задач

Перетащи задачу выше или ниже другой задачи в той же колонке.

После отпускания карточка останется на том месте, куда ты её положил.

### Вложение задачи внутрь другой

Во время перетаскивания у карточек появляется маленький квадрат в углу.

Если перетащить задачу на этот квадрат и отпустить, задача станет подзадачей выбранной карточки и попадёт внутрь неё в колонку **Запланировано**.

### Вынос задачи выше по пути

Во время перетаскивания можно отпустить задачу на один из пунктов хлебных крошек.

Например, если ты находишься здесь:

```text
Главная / Поиск работы / Резюме
```

то задачу можно перетащить на:

```text
Главная
```

или на:

```text
Поиск работы
```

Так задача будет вынесена на выбранный уровень.

## Правила статусов

В проекте используется асимметричная логика статусов.

### Снизу вверх

Если внутри задачи появилась активность, родительская задача становится **В процессе**.

То есть если хотя бы одна вложенная задача перешла из **Запланировано** в **В процессе** или **Сделано**, родитель тоже считается начатым.

Но родитель **не становится автоматически Сделано**, даже если все его подзадачи завершены.

Это сделано специально. Например:

```text
Сварить борщ
├── Купить продукты — Сделано
└── Помыть овощи — Сделано
```

Даже если подготовительные подзадачи выполнены, это ещё не значит, что борщ уже сварен.

### Сверху вниз

Если родительскую задачу перенести в **Сделано**, все её вложенные задачи тоже станут **Сделано**.

Это удобно, когда ты явно говоришь системе: большая задача завершена, значит всё внутри неё тоже можно считать завершённым.

## Задачи-ссылки

Иногда разные большие задачи имеют общие подзадачи.

Например:

```text
Поиск работы
└── Составить резюме
```

и:

```text
Поддерживать /\/erds
└── Составить резюме
```

Чтобы не создавать два независимых дубля, можно создать **ссылку на уже существующую задачу**.

### Как создать ссылку

1. Найди задачу через поиск.
2. В результатах поиска нажми кнопку **+ ссылка**.
3. В текущую доску будет добавлена карточка-ссылка.

### Как работает ссылка

Задача-ссылка указывает на оригинальную задачу.

Если изменить статус такой задачи в одном месте, он изменится и в другом месте тоже.

Если удалить ссылку, оригинальная задача не удалится.

Если удалить оригинальную задачу, ссылки на неё будут очищены.

## Поиск

Поиск находится справа от заголовка **Рекурсивная канбан-доска**.

Он ищет по:

- названию задачи;
- описанию задачи.

В результатах показывается путь до найденной задачи.

Можно:

- открыть найденную задачу;
- создать ссылку на неё в текущей доске.

## Экспорт и импорт

### Экспорт

Открой меню `⋯` справа сверху и нажми:

```text
Экспорт JSON
```

Браузер скачает файл с текущим состоянием доски.

### Импорт

Открой меню `⋯` и нажми:

```text
Импорт JSON
```

Можно выбрать ранее экспортированный `.json` или `.txt` файл.

После импорта состояние доски будет восстановлено.

---

## Хранение данных

Проект хранит данные двумя способами:

1. Автоматически в `localStorage` браузера.
2. Вручную через экспорт JSON.

Важно: `localStorage` привязан к конкретному браузеру и конкретному локальному файлу/адресу.

Чтобы не потерять задачи, периодически делай экспорт JSON.

---

## Структура данных

Внутри проект использует дерево задач.

У каждой задачи есть примерно такие поля:

```json
{
  "id": "task_1",
  "parentId": "root",
  "title": "Сварить борщ",
  "description": "Большая задача с подготовительными шагами",
  "status": "planned",
  "children": ["task_2", "task_3"],
  "createdAt": 1710000000000,
  "updatedAt": 1710000000000
}
```

Задача-ссылка имеет отдельный тип:

```json
{
  "id": "task_10",
  "type": "link",
  "targetId": "task_5",
  "parentId": "task_6"
}
```

## Ограничения

Проект сделан как простой однофайловый инструмент, поэтому у него есть ограничения:

- нет серверной синхронизации между устройствами;
- нет многопользовательского режима;
- нет авторизации;
- нет истории изменений;
- нет защиты от ручного повреждения JSON при редактировании экспортированного файла;
- большие доски могут начать тормозить, если задач станет очень много.

## Назначение проекта

Эта доска подходит для задач, которые удобно раскладывать рекурсивно:

- личные планы;
- обучение;
- проекты;
- поиск работы;
- разработка;
- саморазвитие;
- бытовые задачи;
- большие задачи с множеством подготовительных шагов.

Главная идея проекта:

> Любая задача может быть не только карточкой, но и отдельной доской.
