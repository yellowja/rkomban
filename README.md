# Рекурсивная канбан-доска

Проект для ведения задач в формате рекурсивного канбана. Работает полностью в браузере, без сервера и базы данных. Данные сохраняются в `localStorage`, также доступен экспорт и импорт через JSON.

Обычная канбан-доска состоит из трёх колонок: **Запланировано**, **В процессе**, **Сделано**. В этом проекте каждая задача может открываться как отдельная вложенная доска с такими же колонками. Так можно бесконечно декомпозировать большие задачи на подзадачи, подподзадачи и так далее.

---

## Возможности

- Три стандартные колонки: Запланировано, В процессе, Сделано.
- Рекурсивная вложенность задач — любая задача может быть отдельной доской.
- Открытие вложенной доски по клику на карточку.
- Drag-and-drop для смены статуса и порядка задач.
- Вложение задачи внутрь другой через зону в углу карточки.
- Перенос задачи на любой уровень через хлебные крошки.
- Задачи-ссылки: одна задача может отображаться в нескольких местах.
- Поиск по названию и описанию с возможностью создать ссылку.
- Навигация назад/вперёд кнопками браузера.
- Пользовательские колонки (добавление, переименование, удаление).
- Экспорт/импорт доски в JSON.
- Автосохранение в `localStorage`.
- Адаптивный интерфейс.

## Быстрый старт

Склонируй репозиторий или скачай файлы проекта, затем открой `index.html` в браузере:

```text
index.html
```

Никакой установки зависимостей не требуется.

---

## Структура проекта

```
index.html          — HTML-каркас
css/style.css       — стили
js/
  state.js          — данные, геттеры, загрузка/сохранение
  logic.js          — бизнес-логика (мутации, persist)
  render.js         — отрисовка DOM
  app.js            — UI-события, инициализация
```

Код разделён по слоям: `state.js` ничего не знает об UI, `logic.js` не вызывает `render()`, `render.js` только читает состояние и строит DOM, `app.js` связывает их вместе.

## Как пользоваться

### Создание задачи

В верхней панели введи название, описание (опционально) и нажми **Добавить задачу**. Задача появится в колонке **Запланировано**.

### Открытие вложенной доски

Кликни по карточке задачи — откроется её внутренняя доска:

```text
Главная / Поиск работы / Составить резюме
```

### Возврат назад

- через хлебные крошки;
- через кнопки браузера **Назад** / **Вперёд**.

---

## Drag-and-drop

### Смена статуса

Перетащи задачу в нужную колонку: **Запланировано**, **В процессе** или **Сделано**.

### Изменение порядка

Перетащи задачу выше или ниже другой в той же колонке.

### Вложение

Во время перетаскивания у карточек появляется квадрат `↘` в углу. Если перетащить задачу на этот квадрат, она станет подзадачей.

### Вынос на уровень выше

Перетащи задачу на один из пунктов хлебных крошек, чтобы вынести её на выбранный уровень.

---

## Правила статусов

Используется асимметричная логика.

### Снизу вверх

Если хотя бы одна вложенная задача перешла из **Запланировано** в **В процессе** или **Сделано**, родитель тоже становится **В процессе**. Но родитель **не становится Сделано автоматически**, даже если все подзадачи завершены:

```text
Сварить борщ
├── Купить продукты — Сделано
└── Помыть овощи — Сделано
```

### Сверху вниз

Если родительскую задачу перенести в **Сделано**, все её вложенные задачи тоже станут **Сделано**.

## Задачи-ссылки

### Как создать

1. Найди задачу через поиск.
2. В результатах нажми **+ ссылка**.
3. В текущую доску будет добавлена карточка-ссылка.

### Как работает

- Ссылка указывает на оригинальную задачу.
- Изменение статуса в любом месте меняет его везде.
- Удаление ссылки не удаляет оригинал.
- Удаление оригинала очищает все ссылки на него.

---

## Поиск

Поле поиска — справа от заголовка. Ищет по названию и описанию. В результатах показывает путь до задачи. Можно открыть задачу или создать ссылку на неё.

---

## Экспорт и импорт

Меню `⋯` → **Экспорт JSON** — скачать файл. **Импорт JSON** — загрузить ранее сохранённый `.json` или `.txt` файл.

---

## Структура данных

Дерево задач. У каждой задачи:

```json
{
  "id": "task_1",
  "parentId": "root",
  "title": "Сварить борщ",
  "description": "Большая задача с подготовительными шагами",
  "status": "planned",
  "children": ["task_2", "task_3"],
  "createdAt": 1710000000000,
  "updatedAt": 1710000000000
}
```

Задача-ссылка:

```json
{
  "id": "task_10",
  "type": "link",
  "targetId": "task_5",
  "parentId": "task_6"
}
```

## Ограничения

- Нет серверной синхронизации.
- Нет многопользовательского режима.
- Нет истории изменений.
- Нет защиты от повреждения JSON при ручном редактировании.
- Большие доски могут тормозить при тысячах задач.
